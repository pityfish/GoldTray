# GoldTray

轻量级跨平台黄金行情监控托盘工具。常驻系统菜单栏 / 任务栏，持续展示招商银行黄金账户·活期的第三方参考买入价，并提供多档价格预警提醒、智能企稳信号与历史走势查看。

> 平台支持：macOS（Apple Silicon）· Windows 10/11（Intel Mac 支持规划于后续版本）
>
> 技术栈：Tauri 2 · Vue 3 · TypeScript · Naive UI · Pinia · Rust · SQLite

---

## 功能特性

### 行情监控

- **托盘常驻显示**：macOS 菜单栏直接显示金价文字（如 `Au ¥837.80 ↑0.57`）；Windows 托盘以图标 + 悬停提示展示
- **定时自动刷新**：Rust 后台轮询，默认 60 秒，可配置 30 / 60 / 120 / 300 秒
- **失败退避重试**：15s → 30s → 60s …，上限为正常轮询间隔
- **请求互斥**：同一时刻仅允许一个行情请求进行（超时 10 秒）
- **数据异常提示**：获取失败时保留最后一次有效报价并标记 `⚠`；行情超过过期阈值显示「已过期」
- **关闭驻留**：点击关闭按钮仅隐藏窗口，托盘继续运行；禁止多开
- **开机自启**：设置页可开启，系统登录后自动运行（macOS LaunchAgent / Windows 注册表）
- **桌面悬浮行情条**：置顶半透明小条持续显示金价（`Au ¥837.50 ↑0.57`），可拖动、位置记忆，
  可拖动边缘调整大小（等比缩放）、调节透明度，托盘菜单勾选开关，
  解决 Windows 无法常驻显示价格文字的问题
- **托盘交互**：左键点击打开主窗口；右键菜单（打开行情 / 预警管理 / 立即刷新 / 退出）

### 价格预警

- **多规则并存**：可创建任意多条独立预警规则，规则间互不干扰
- **方向条件**：上涨达到（≥）/ 下跌达到（≤）目标价
- **穿越触发**：价格穿越阈值才触发，而非持续满足就反复通知
- **二次确认**：默认连续两次有效行情满足条件才触发，降低瞬时毛刺误报- **冷却时间**：每条规则独立冷却期（5～120 分钟可选），冷却期内禁止重复通知
- **触发方式**：
  - `仅提醒一次`：触发后自动停用
  - `重复提醒`：价格回到安全侧后自动重新激活
- **触发状态持久化**：规则启用状态、触发状态、冷却计时均随 SQLite 保存，重启后不丢失
- **触发记录**：预警页时间线展示历史触发
- **行情失效保护**：行情数据超过过期阈值（默认 5 分钟）时不触发新提醒
- **卖出价差估算**：当前数据源仅提供客户买入参考价；客户卖出价预警可按「目标卖出价 + 价差」换算为等效买入价监控，通知中会提示到银行 App 核对实际价格

### 历史走势与智能企稳

- **历史走势图**：主页 ECharts 绿色面积图，支持 2天/14天/1月/3月/6月/12月 六档周期切换，
  悬停显示时段最低/最高/平均，附区间统计（最高、最低、平均、涨跌幅），深浅色主题自适应
- **历史数据缓存**：SQLite 按周期独立缓存（48H 每 15 分钟、14d 每 30 分钟后台刷新，
  更长周期按需拉取），网络异常时自动降级显示旧数据并标注
- **智能企稳预警**：新增独立预警类型，三级识别状态机——
  ① 价格进入观察区（≤ 观察价）→ ② 连续有效交易日未明显创新低且波动收窄 → 初步企稳，
  ③ 突破近几日高点并连续有效小时窗口保持 → 反弹确认
- **有效交易日识别**：自动排除未完成交易日、数据点过少、全天重复报价（休市）的日期，
  避免把休市重复报价误判为企稳
- **信号失效保护**：再次明显创新低、数据缺失、修改配置等场景自动撤销信号；
  状态变更全程留痕（状态记录时间线），历史信号不因失效而删除
- **企稳通知**：按阶段推送「初步企稳」「反弹确认」系统通知，含冷却去重，
  仅提示参考信号、不含交易指令
- **图表联动**：走势图叠加企稳观察价水平线；首页企稳状态卡可查看完整判断依据

## 下载与安装

### 方式一：下载安装包（推荐普通用户）

前往 [GitHub Releases](https://github.com/pityfish/GoldTray/releases) 页面，按系统下载对应安装包：

| 系统 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `GoldTray_<版本>_aarch64.dmg` | M1/M2/M3/M4 系列 |
| Windows 10/11 | `GoldTray_<版本>_x64-setup.exe`（或 `.msi`） | 64 位 |

**macOS 安装步骤：**

1. 双击打开 `.dmg`，将 GoldTray 拖入「应用程序」文件夹
2. 首次打开若提示 **"GoldTray 已损坏，无法打开"**（未签名应用被 macOS 隔离的常见提示，应用本身没有问题）：

   打开「终端」，执行以下命令移除隔离属性后即可正常打开：

   ```bash
   xattr -dr com.apple.quarantine /Applications/GoldTray.app
   ```

   > 说明：本应用暂未购买 Apple Developer 签名公证，浏览器下载的文件会被 macOS 打上隔离标记。右键「打开」的方式在新版 macOS（Sequoia 及以后）已不再可用，请使用上述命令。
3. 首次使用请在 系统设置 → 通知 → GoldTray 中允许通知，预警才能弹出提醒

**Windows 安装步骤：**

1. 双击 `GoldTray_x64_Setup.exe`，按安装向导完成安装
2. Windows 10 若缺少 WebView2 运行时，安装程序会提示下载安装
3. 首次启动后建议在 Windows 设置 → 系统 → 通知 中确认 GoldTray 通知已开启

### 方式二：从源码构建安装

```bash
# 1. 准备环境：安装 Node.js 20+、pnpm 9+、Rust 稳定版（详见「本地开发」）
# 2. 克隆并构建
git clone https://github.com/pityfish/GoldTray.git && cd GoldTray
pnpm install
pnpm tauri build

# 3. 构建产物位置
# macOS：src-tauri/target/release/bundle/dmg/GoldTray_<版本>_aarch64.dmg
#        src-tauri/target/release/bundle/macos/GoldTray.app（可直接运行）
# Windows：src-tauri/target/release/bundle/nsis/GoldTray_<版本>_x64-setup.exe
```

得到安装包后按「方式一」的对应系统步骤安装即可。

### 卸载

| 系统 | 操作 |
|---|---|
| macOS | 退出应用（托盘右键 → 退出），将 GoldTray 移到废纸篓；如需清除数据，删除 `~/Library/Application Support/com.goldtray.app/` |
| Windows | 退出应用后，在 系统设置 → 应用 中卸载；数据位于 `%APPDATA%/com.goldtray.app/` |

## 使用指南

### 1. 启动与托盘

启动应用后，主窗口自动打开，同时系统托盘常驻：

- **macOS**：屏幕顶部菜单栏出现 `Au ¥837.80 ↑0.57` 字样的图标，金价实时可见
- **Windows**：任务栏右下角通知区出现黄金图标，鼠标悬停可查看当前参考价与获取时间

托盘显示状态说明：

| 显示 | 含义 |
|---|---|
| `Au ¥838.70` / `Au ¥838.70 ↑0.68` | 正常行情，↑↓ 为相对变化参考值 |
| `Au ¥838.70 · 已过期` | 长时间未获取到新行情，数据可能过时 |
| `Au --.--` | 尚未获取到任何有效行情 |
| `Au ¥838.70 ⚠` | 最近一次获取失败，显示的是最后一次有效报价 |

### 2. 托盘操作

| 操作 | 效果 |
|---|---|
| 左键点击托盘图标 | 打开或聚焦主窗口 |
| 右键点击托盘图标 | 弹出菜单：打开行情 / 预警管理 / 立即刷新 / 悬浮行情条 / 菜单栏显示 / 退出 |
| 勾选「悬浮行情条」 | 在桌面显示置顶悬浮行情小条，可拖动到任意位置，位置自动记忆；取消勾选隐藏 |
| 勾选「菜单栏显示」 | 控制托盘图标旁是否显示价格文字（仅 macOS 生效），关闭后仅保留图标 |
| 点击主窗口关闭按钮 `×` | 仅隐藏窗口，托盘继续运行、预警继续生效 |
| 退出应用 | 右键托盘菜单 →「退出」，此时预警停止 |

> 两项显示开关的状态都会持久化，重启后保持；也可在主窗口「设置 → 显示设置」中配置，与托盘菜单联动。

### 3. 查看行情（主窗口 · 行情页）

打开主窗口即可看到：

- 当前参考价大字展示（元/克），带涨跌变化
- 「第三方参考买入价」标签——明确这不是银行官方成交价
- 最近获取时间；若超时未更新会显示「数据已过期」警告
- 「立即刷新」按钮手动拉取最新行情

### 4. 创建价格预警（主窗口 · 预警页）

1. 切换到「预警」页，点击右上角**新增预警**
2. 填写规则：
   - **规则名称**：如「第一轮加仓观察」
   - **监控价格**：客户买入参考价（默认）；或客户卖出价（需先在设置中填写价差估算）
   - **预警方向**：上涨达到（≥）/ 下跌达到（≤）
   - **目标价格**：元/克
   - **预警方式**：仅提醒一次 / 重复提醒
   - **冷却时间**：触发后多久内不再重复通知
3. 保存后规则立即生效，规则卡片会显示当前状态（监控中 / 已处于目标区间 / 无法准确监控 / 已停用）

预警触发时：

- 系统弹出原生通知，内容包含目标价、当前参考价，并建议打开银行 App 核对实际价格（**通知不含任何买卖指令**）
- 「仅提醒一次」规则触发后自动停用；「重复提醒」规则需等价格回到安全侧后自动重新激活
- 所有触发都会记录在预警页底部的「触发记录」时间线中

> 首次触发通知时，macOS 会请求通知权限，请选择「允许」；如未弹出，请到 系统设置 → 通知 → GoldTray 开启。

### 5. 常用设置（主窗口 · 设置页）

| 想做什么 | 操作 |
|---|---|
| 开机自动运行 | 通用设置 → 开机自启 |
| 开关悬浮行情条 / 菜单栏显示 | 显示设置（与托盘菜单联动，状态持久化） |
| 调整刷新频率 | 行情设置 → 刷新频率（30/60/120/300 秒）|
| 关闭涨跌显示 | 行情设置 → 显示涨跌金额 |
| 调整"数据过期"判定时长 | 行情设置 → 数据过期阈值 |
| 关闭所有系统通知 | 通知设置 → 开启原生通知 |
| 启用客户卖出价预警 | 卖出价差估算 → 填写价差（元/克），如 5.00 |

### 6. 典型使用场景

以「分批加仓观察」为例：

1. 在设置页把刷新频率调为 30 秒
2. 预警页依次创建下跌预警：¥835.00、¥805.00（可命名第一轮/第二轮加仓观察）
3. 关闭主窗口，正常工作即可——金价跌到目标价时系统通知会自动弹出
4. 收到通知后打开招商银行 App 核对实际价格，再自行决定是否交易

## 本地开发

### 环境要求

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 20 | 推荐 LTS（CI 使用 22） |
| pnpm | ≥ 12 | 包管理器（CI 锁定 12.16.1） |
| Rust | 稳定版 | 通过 [rustup](https://rustup.rs) 安装 |
| Tauri 系统依赖 | — | macOS 需 Xcode Command Line Tools；Windows 需 WebView2（Win11 自带） |

### 常用命令

```bash
pnpm install          # 安装前端依赖

pnpm tauri dev        # 开发模式运行（自动启动 vite + rust 编译）
pnpm tauri build      # 构建：macOS 产出 .dmg / .app，Windows 产出 .exe / .msi

# 前端单独验证
pnpm typecheck        # Vue 类型检查（vue-tsc）
pnpm test:ui          # Playwright E2E 回归（浏览器内 mock Tauri IPC，首次需 pnpm exec playwright install chromium）

# Rust 端单独验证
cd src-tauri
cargo check           # 编译检查
cargo test            # 单元测试（预警 7 + 企稳 10 + 存储 4，共 21 个用例）
```

> 图标源文件在 `build-src/icon.svg`，修改后执行 `pnpm tauri icon build-src/icon.svg` 重新生成全套图标。

### 构建发布（GitHub Actions）

Windows 安装包无法在 macOS 上交叉编译，双平台安装包通过 GitHub Actions 自动构建（配置见 `.github/workflows/build.yml`）：

```bash
# 发布新版本：打 tag 并推送即可
git tag v1.3.0
git push origin v1.3.0
```

构建流程：安装依赖 → 前端构建检查 + 类型检查 → Rust 单元测试（`--locked`）→ macOS（Apple Silicon）与 Windows（x64）并行打包 → 自动创建 GitHub Release 并上传 `GoldTray_<版本>_aarch64.dmg`、`GoldTray_<版本>_x64-setup.exe`、`GoldTray_<版本>_x64_en-US.msi`。

此外 `.github/workflows/verify.yml` 在 Pull Request 上自动运行类型检查、Playwright E2E 回归（Linux）与 Rust 单元测试（macOS + Windows 矩阵）。

也可在仓库 Actions 页面手动触发（Run workflow）验证构建流程，不上传产物。

## 配置与数据存储

所有数据本地存储，不上传任何服务器，无需银行账户登录。

| 项目 | 位置 |
|---|---|
| SQLite 数据库 | macOS：`~/Library/Application Support/com.goldtray.app/goldtray.db`；Windows：`%APPDATA%/com.goldtray.app/` |

数据库表：

| 表 | 用途 |
|---|---|
| `price_alerts` | 预警规则及触发状态（armed / confirm_hits / last_triggered） |
| `alert_history` | 预警触发记录（含通知发送状态） |
| `gold_history_bars` | 历史行情数据缓存 |
| `stabilization_alerts` | 智能企稳规则及状态 |
| `stabilization_events` | 企稳状态变更留痕（时间线） |
| `stabilization_notification_times` | 企稳通知冷却计时 |
| `app_settings` | 键值配置（刷新间隔、通知开关、过期阈值、卖出价差估算等） |

主要设置项：

| 设置 | 默认值 | 说明 |
|---|---|---|
| 刷新间隔 | 60 秒 | 可选 30 / 60 / 120 / 300 秒 |
| 数据过期阈值 | 300 秒 | 超过该时长未获取到新行情则标记「已过期」并暂停触发预警 |
| 原生通知 | 开启 | 关闭后预警仅记录，不发系统通知 |
| 卖出价差估算 | 关闭 | 填写价差（元/克）后启用客户卖出价规则监控 |

## 数据来源与免责声明

- 行情数据来源为第三方「汇率速递」接口（`api2.huilvsudi.com`），展示的是**客户买入参考价**，并非招商银行官方实时成交价。
- 本应用不会将第三方参考价伪装为银行官方价格，界面与通知中均明确标注数据来源。
- 该接口为非官方渠道，存在变更、限流或失效的可能；请勿将本应用作为唯一交易依据。
- 本应用仅提供行情展示与提醒功能，不执行任何实际交易，不对盈利作出任何保证；投资决策请以银行 App 实际价格为准，风险自负。
- 应用不收集、不上传任何个人身份数据；不要求也不会存储银行账号、密码、Cookie 或 Token。
